# Portfólio — David Cristian

Site pessoal de portfólio: apresentação, habilidades, experiência na Agência Wave e trabalhos de design gráfico, edição de vídeo, identidade visual e sites.

**Site no ar:** https://david-cristian.vercel.app

## Seções

- Sobre mim e habilidades (design, vídeo, sites, Meta Ads, programação)
- Experiência — Agência Wave (2023–hoje)
- Galerias de design, identidade visual, vídeos verticais e sites
- Contato

## Stack

HTML, CSS e JavaScript puros, num único `index.html`, sem build. Mídias em `midia/`. Deploy na Vercel.

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```
